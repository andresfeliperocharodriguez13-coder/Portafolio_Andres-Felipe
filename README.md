2. Abre la carpeta del proyecto.

Si usas **Visual Studio Code**, también puedes instalar la extensión *Live Server* y darle clic en **Go Live**.

---

## 🚀 Cómo publicarlo en GitHub Pages

1. Sube el proyecto a tu repositorio en GitHub.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/ (root)**, y dale **Save**.
5. Espera un par de minutos. GitHub te mostrará el enlace de tu página.

> ⚠️ Sube también la carpeta `assets`, si no tu foto no aparecerá.

## 🌿 Cómo trabajé con Git

### Ramas (Git Flow)

| Rama | Para qué sirve |
|---|---|
| `main` | Versión final, la que está publicada |
| `develop` | Donde se junta todo el trabajo antes de publicar |

### Commits (Conventional Commits)

Cada commit empieza con un tipo y explica en pocas palabras lo que se hizo:

| Tipo | Se usa para | Ejemplo |
|---|---|---|
| `feat` | Agregar algo nuevo | `feat: ✨ agrega sección de proyectos` |
| `style` | Cambios de diseño | `style: 💄 agrega diseño responsive` |
| `fix` | Arreglar un error | `fix: 🐛 corrige menú en celular` |
| `docs` | Documentación | `docs: 📝 agrega README` |
| `refactor` | Ordenar código sin cambiar lo que hace | `refactor: ♻️ simplifica animaciones` |
